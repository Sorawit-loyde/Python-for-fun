# Python for Fun

This is a mini project of Python I made.

## Overview

A collection of mini Python projects for fun and practice. Explore different concepts and experiment with Python programming.

## Requirements

- Python 3.7+

## Installation

1. **Clone the repository:**
   ```sh
   git clone https://github.com/Sorawit-loyde/Python-for-fun.git
   cd Python-for-fun
   ```

2. **Install any dependencies:**
   If a `requirements.txt` is present:
   ```sh
   pip install -r requirements.txt
   ```

## Usage

Run individual scripts as needed:
```sh
python script_name.py
```
